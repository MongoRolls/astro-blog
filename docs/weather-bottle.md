# 天气玻璃瓶

独立交付为 `public/widgets/weather-bottle/index.html`。保存为 `index.html` 后联网打开即可使用，CSS、场景逻辑、纹理与环境均内联；唯一必需的外部资源为固定版本 Three.js 0.170.0（jsDelivr，失败回退相同版本 unpkg）。不需要构建或后端即可观察默认阳光场景、转动瓶子和擦雾。

## 集成

中英文首页文章列表之后直接渲染 `WeatherBottle.astro`，默认只显示透明玻璃瓶、阳光、水面与小船。宿主、画布与折射缓冲均透明，无外框、卡片底色、标题说明块、按钮、工具条、温湿度面板或下载入口。首页嵌入宽度为正文列的一半（240–340px，且不超过列宽）、比例 4:3：桌面约 337×253px，手机约 240×180px，作为文章列表后的小型点缀；保留页面本身的明暗背景与正文宽度。独立 HTML 仍使用原有的较大取景。

接近视口 240px 自动加载场景模块及 Three.js；远离内容区时不提前下载或查询天气。离屏、页面隐藏时暂停，Astro 导航离开取消初始化和天气请求，释放动画、监听、观察器和 WebGL 资源；返回后创建单个新实例。重试通过轻点场景或按 Enter 在原地完成，仅错误时显示简短提示。

桌面拖动玻璃观察，未按下鼠标时轻扫瓶身擦雾，两种动作互斥。手机横滑观察、轻点玻璃擦去局部雾气，纵向手势留给页面滚动，保留浏览器双指缩放。连续触摸擦雾与显式模式切换已移除。方向键观察，Home 回正，空格暂停/继续；减少动态效果时默认暂停。快速往返拖动仍可摇起波浪与微型暴风雪。键盘说明、状态、天气数据和数据来源放在无障碍描述中，正常画面不显示文字控件。

`src/components/weather-bottle/` 是共享源码：`scene.js` 提供可销毁的场景实例，`scene.css` 的选择器限制在 `.weather-scene` 内，`markup.html` 使用宿主范围内的数据属性而非全局 ID。`pnpm build:weather` 将三者生成完整内联的单文件；`pnpm test:weather` 先检查生成物一致性，避免下载文件与 Astro 组件逻辑漂移。独立 HTML 不需要运行生成命令即可使用。

## 天气数据

站点打开时通过同源 `/api/weather` 使用 Vercel 已有的城市级请求信息。已有的独立 Vercel Function 不改变 Astro 静态输出模式，不需要密钥、数据库或付费订阅。只发送四舍五入到 0.1° 的粗略坐标到 Open-Meteo；不转发访客 IP、cookies、User-Agent 或其它请求头，不持久化位置。浏览器不使用 Geolocation，不调用第三方 IP 定位、不弹定位授权、不提供城市选择。

- 默认未查询/缺少地区/超时/无效或过旧数据/接口失败：保持可交互默认阳光场景；无障碍描述标明“默认阳光场景 · 非实况”，不编造温湿度。
- 查询成功：瓶内天气自动映射；大致地区、摄氏温度、相对湿度、更新时间和 Open-Meteo 来源保留在屏幕阅读器可访问的描述中。IP 地区可能受 VPN 影响；这是模型当前天气数据，并非本站传感器实测。
- WMO 码覆盖晴、多云、雾、雨、雪和雷暴。手动演示天气、刷新天气与模式切换按钮已移除；导航后迟到响应不能更新旧实例。
- 浏览器每 15 分钟自动更新，回到视口时按数据年龄补查，失败后下个周期重试；请求另有 1 分钟节流；服务端以粗略网格缓存 15 分钟，最多 200 项。响应禁止共享 CDN 缓存，避免跨访客地区混淆。上游请求 5 秒超时。
- `file://` 以及普通静态托管不具有 Vercel 请求地理信息，因此独立文件正常展示默认场景，不尝试替代定位服务。`?live=1` 只启用同源可选接口；不存在也能降级。

官方依据：[Vercel 请求地理头](https://vercel.com/docs/headers/request-headers)、[Vercel Functions](https://vercel.com/docs/functions)、[Open-Meteo API 与天气码](https://open-meteo.com/en/docs)。Open-Meteo 免费 API 限非商业用途，数据适用 CC BY 4.0；无障碍描述保留来源链接与许可标记。本个人博客目前无订阅/广告；若将来商业化，需重新核对其[使用条款和限额](https://open-meteo.com/en/terms)，本次没有购买服务。

## 几何与交互

- 玻璃为带厚度的旋转曲面。先将实际内部景物渲染到透明缓冲，再按表面法线采样 RGBA 折射，叠加 Fresnel 边缘与柔光反射。最终玻璃片元保留透明度并按预乘 alpha 合成，不填入固定颜色背景。页面背景由浏览器透过玻璃显示；该近似只折射瓶内 3D 景物，不扭曲页面 DOM，也不是光线追踪。
- 瓶子最大倾角约 19.5°；液面法线追随世界重力，斜率由有阻尼弹簧求解，波浪与水体上下边界共享高度函数。极端斜率有几何上限，水体不越过内壁。该方案是受约束的微缩动画，并非完整流体模拟。
- 木船包含空心船壳、船舷、底板、横凳、金属钉与程序化木纹。船中心高度直接采样水面，姿态平滑追随局部水面法线；漂移范围为安全内圈。雪花命中船体时增加露出部位积雪，入水后逐渐融散，换天气后积雪消融。
- 云层有独立小幅运动；雨滴命中水面生成有生命周期的涟漪。雪具有异速、异尺寸、横向飘移。快速往返拖动驱动晃荡/旋风雪，停止后衰减。
- 雾气直接绘于瓶身表面 UV 纹理，射线命中才生效；使用实际高度映射、连续柔边插值和横向接缝包裹。桌面悬停擦雾与按下拖动互斥；触屏仅在没有滑动的轻点结束时擦雾，滚动和拖动不产生擦痕。
- 雷暴仅单个 0.38 秒柔和脉冲，间隔至少 7 秒；减少动态效果时默认暂停且不闪电。场景支持手动暂停、页面隐藏/离开视口暂停、导航离开后释放。

## 预算与验证

触屏或宿主窄于 600px 时为 180 雪粒子 + 100 雨滴、上限 30 fps（首页嵌入和独立页都属此档），更宽的宿主为 300 + 170。像素比上限桌面 2 / 触屏 1.75，并把绘图缓冲限制在约 36 万像素内：首页小瓶以接近设备像素渲染细边，大尺寸独立页自动降低像素比。折射目标为绘图缓冲尺寸的 75%，重用粒子和涟漪池，典型单次场景绘制少于 90 draw calls、4 万三角形（折射和最终画面共两次场景绘制）。实际速度取决于 GPU；软件 WebGL 不代表真实手机帧率。

- `pnpm test:weather`：天气接口坐标最小化、缺失/异常位置、缓存隔离、过旧数据、限流和上游故障。
- `pnpm test:browser`：包括原有博客回归，以及天气瓶几何边界、水船联动、雨雪雷暴、积雪融散、透明像素/玻璃透光、首页约为正文列一半的 4:3 尺寸、无可见控件、悬停/拖动隔离、摇晃、触摸、缩放、减少动效、天气映射/竞态/降级、CDN 与 WebGL 错误以及首页原生挂载、离屏暂停、导航销毁/返回、重复挂载、延迟 CDN 竞态、页内重试和手机滚动隔离。
- 浏览器测试仅用明确标为 Test city 的模拟地区，不获取测试者真实位置。测试加载真正的固定版本 Three.js，并核对 SHA-256；本地网络证书有差异时可通过 `WEATHER_THREE_FIXTURE` 指向预先下载的同一文件，不替换 WebGL 或场景实现。
- `?debug=1` 暴露只读诊断快照、RGBA 像素统计与同步画布截图，供几何、透明度与联动断言使用；默认不暴露。截图仅作内部 QA，不随用户 HTML 上传。
