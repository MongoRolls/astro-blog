# 天气玻璃瓶

独立交付为 `public/widgets/weather-bottle/index.html`。保存为 `index.html` 后联网打开即可使用，CSS、场景逻辑、纹理与环境均内联；唯一必需的外部资源为固定版本 Three.js 0.170.0（jsDelivr，失败回退相同版本 unpkg）。不需要构建或后端才能观察、擦雾和切换演示天气。

## 集成

中英文首页文章列表之后插入 `WeatherBottle.astro`。默认无 WebGL、iframe、天气请求与 Three.js 下载；点击打开才创建 iframe，收起或 Astro 页面切换即移除。主题通过同源消息同步，展开观察和下载分别提供完整页面及原始 HTML。保留现有小项目卡片、正文和导航行为。

## 天气数据

站点打开时通过同源 `/api/weather` 使用 Vercel 已有的城市级请求信息。新增的独立 Vercel Function 不改变 Astro 静态输出模式，不需要密钥、数据库或付费订阅。只发送四舍五入到 0.1° 的粗略坐标到 Open-Meteo；不转发访客 IP、cookies、User-Agent 或其它请求头，不持久化位置。浏览器不使用 Geolocation，不调用第三方 IP 定位、不弹定位授权、不提供城市选择。

- 默认未查询/缺少地区/超时/无效或过旧数据/接口失败：保持可交互默认雪景，标明“默认场景 · 非实况”，不显示伪造温湿度。
- 查询成功：显示大致地区、摄氏温度、相对湿度、更新时间和 Open-Meteo 来源。IP 地区可能受 VPN 影响；这是模型当前天气数据，并非本站传感器实测。
- WMO 码覆盖晴、多云、雾、雨、雪和雷暴。手动雨雪雷暴切换进入演示模式，保留明确标注的当地数据；迟到响应不能覆盖用户选择。
- 浏览器最多每 15 分钟自动更新，显式刷新节流 1 分钟；服务端以粗略网格缓存 15 分钟，最多 200 项。响应禁止共享 CDN 缓存，避免跨访客地区混淆。上游请求 5 秒超时。
- `file://` 以及普通静态托管不具有 Vercel 请求地理信息，因此独立文件正常展示默认场景，不尝试替代定位服务。`?live=1` 只启用同源可选接口；不存在也能降级。

官方依据：[Vercel 请求地理头](https://vercel.com/docs/headers/request-headers)、[Vercel Functions](https://vercel.com/docs/functions)、[Open-Meteo API 与天气码](https://open-meteo.com/en/docs)。Open-Meteo 免费 API 限非商业用途，数据适用 CC BY 4.0；界面提供来源链接。本个人博客目前无订阅/广告；若将来商业化，需重新核对其[使用条款和限额](https://open-meteo.com/en/terms)，本次没有购买服务。

## 几何与交互

- 玻璃为带厚度的旋转曲面。先渲染实际内部景物，再按表面法线采样折射，并叠加 Fresnel 边缘与程序化柔光箱反射；这是屏幕空间薄玻璃近似，不是光线追踪。
- 瓶子最大倾角约 19.5°；液面法线追随世界重力，斜率由有阻尼弹簧求解，波浪与水体上下边界共享高度函数。极端斜率有几何上限，水体不越过内壁。该方案是受约束的微缩动画，并非完整流体模拟。
- 木船包含空心船壳、船舷、底板、横凳、金属钉与程序化木纹。船中心高度直接采样水面，姿态平滑追随局部水面法线；漂移范围为安全内圈。雪花命中船体时增加露出部位积雪，入水后逐渐融散，换天气后积雪消融。
- 云层有独立小幅运动；雨滴命中水面生成有生命周期的涟漪。雪具有异速、异尺寸、横向飘移。快速往返拖动与“轻摇一下”共同驱动晃荡/旋风雪，停止后衰减。
- 雾气直接绘于瓶身表面 UV 纹理，射线命中才生效；使用实际高度映射、连续柔边插值和横向接缝包裹。擦雾模式与观察模式互斥。方向键/Home 亦可观察/回正。
- 雷暴仅单个 0.38 秒柔和脉冲，间隔至少 7 秒；减少动态效果时默认暂停且不闪电。场景支持手动暂停、页面隐藏/离开视口暂停、关闭后释放。

## 预算与验证

桌面 300 雪粒子 + 170 雨滴，移动端 180 + 100；DPR 上限分别为 1.6 / 1.25；移动端上限 30 fps。折射目标为绘图缓冲尺寸的 75%，重用粒子和涟漪池，典型单次场景绘制少于 90 draw calls、4 万三角形（折射和最终画面共两次场景绘制）。实际速度取决于 GPU；软件 WebGL 不代表真实手机帧率。

- `pnpm test:weather`：天气接口坐标最小化、缺失/异常位置、缓存隔离、过旧数据、限流和上游故障。
- `pnpm test:browser`：包括原有博客回归，以及天气瓶几何边界、水船联动、雨雪雷暴、积雪融散、擦雾隔离、摇晃、触摸、缩放、减少动效、天气映射/竞态/降级、CDN 与 WebGL 错误和首页按需加载。
- 浏览器测试仅用明确标为 Test city 的模拟地区，不获取测试者真实位置。测试加载真正的固定版本 Three.js，并核对 SHA-256；本地网络证书有差异时可通过 `WEATHER_THREE_FIXTURE` 指向预先下载的同一文件，不替换 WebGL 或场景实现。
- `?debug=1` 暴露只读诊断快照，供几何与联动断言使用；默认不暴露。截图仅作内部 QA，不随用户 HTML 上传。
