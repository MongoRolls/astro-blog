# 本地天气卡

中英文首页文章列表下方的磨砂玻璃天气卡展示大致地区、摄氏温度、天气状况、湿度和观测时间。地区由 Vercel 提供，可能受 VPN 影响。天气数据由 Open-Meteo 提供，采用 CC BY 4.0 许可。缺少地区、观测超过两小时或请求失败时显示本地化的不可用状态。

天气卡只在接近视口且页面可见时查询同源 `/api/weather`，每 15 分钟刷新。组件离开文档时中止请求和定时器。接口仅向 Open-Meteo 发送四舍五入到 0.1° 的坐标，同一函数实例内按网格合并查询并缓存 15 分钟，最多 200 项。浏览器不申请定位权限。

`src/components/WeatherCard.astro` 同时用于首页与独立文件。原地址 `/widgets/weather-bottle/index.html` 继续有效。独立文件内联样式和脚本，保存到本地后仍可打开。支持 `?lang=en`、`?theme=dark|light`。托管于具有同源接口的站点时，追加 `live=1` 可开启实况。

`pnpm test:weather` 运行天气 API 的 Node 测试。仓库现有浏览器套件的天气卡用例使用模拟天气数据，覆盖双语展示、小屏布局、独立入口、失效恢复和 Astro 页面切换。
