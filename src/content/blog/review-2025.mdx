个人的场景方案：

| 场景  | 主力工具                      | 备注                              |
| ----- | ----------------------------- | --------------------------------- |
| IDE   | Cursor + Gemini 3 Flash       | 性价比高，开发舒适 |
| CLI   | Claude Code + cc switch + GLM | 适合丢琐碎任务跑着                |

- **从写代码到审代码**：AI 接管低级任务后，程序员需要更扎实的基本功来审查和修正 AI 生成的代码。
- **经验溢价**：就像从自行车到汽车，操作更简单，但预判和掌控力（经验）更重要。
- **软实力决定上限**：表达能力、逻辑抽象和跨领域沟通成为核心竞争力。
